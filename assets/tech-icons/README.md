# Technology logos

SVG logos from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons), original variants without wordmarks.

The assets are stored locally so the portfolio does not depend on a CDN. See [LICENSE.txt](./LICENSE.txt) for Devicon's MIT license. Brand names and logos belong to their respective owners.

The developer portfolio uses [Font Awesome Free](../fontawesome/README.md) for interface and conceptual icons (UML, MERISE, Scrum, etc.).

Country flag SVGs (Morocco, France, United Kingdom and Italy) are from [flag-icons v7.5.0](https://github.com/lipis/flag-icons/tree/v7.5.0/flags/4x3), under the [MIT license](./FLAGS-LICENSE.txt). They identify the language badges, not technology brands.
