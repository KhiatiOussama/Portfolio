# Font Awesome Free

Selected solid and brand icons from [Font Awesome Free 6.7.2](https://github.com/FortAwesome/Font-Awesome/tree/6.7.2/svgs).

Icons are used under CC BY 4.0. JavaScript code is MIT licensed. Full attribution and license terms are in [LICENSE.txt](./LICENSE.txt).

The local bundle exposes `window.FontAwesomeIcons.icon(name)` and returns an accessible decorative SVG. Only included icon names are accepted; unknown names fall back to `code`. No CDN, webfont or runtime download is required.
